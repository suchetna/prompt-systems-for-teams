# Prompt Systems for Teams

Reusable prompt frameworks, prompt packs, and evaluation patterns for real business teams.

## Why this exists

Most teams are not struggling because they lack access to AI tools. They are struggling because prompting is inconsistent, undocumented, and hard to reuse across workflows.

This repository is a working library of prompt structures, team-ready prompt packs, and practical guidance for making prompting more systematic inside organizations.

## What’s inside

- Prompt frameworks for common business tasks
- Team-ready prompt packs
- Prompt review and QA checklists
- Role-based prompting examples
- Patterns for reusable prompt systems

## Who this is for

- Team leads introducing AI into workflows
- Knowledge workers using AI regularly
- Consultants and enablement practitioners
- Organizations trying to move beyond one-off prompting

## Working principle

Treat prompts as systems, not magic spells.
