# Prompt Review Checklist

Use this checklist before a prompt or prompt set is shared with a team.

## 1. Purpose
- Is the outcome of this prompt clear?
- Is it tied to a real task in the workflow?
- Is there an example of a good output?

## 2. Inputs
- Does the prompt ask for the right inputs?
- Are placeholders clearly marked?
- Are there hidden assumptions about context or data?

## 3. Instructions
- Is the instruction written in plain language?
- Does it specify audience, tone, and format?
- Does it set limits on what to avoid?

## 4. Structure
- Is the prompt broken into clear sections?
- Are multi-step instructions easy to follow?
- Is the requested output structure explicit?

## 5. Guardrails
- Does the prompt reduce the risk of made-up facts?
- Does it say what to do when information is missing?
- Does it include review expectations where needed?

## 6. Testing
- Has the prompt been tested with multiple examples?
- Has someone else reviewed the outputs?
- Are common failure modes documented?

## 7. Reuse
- Is the prompt named clearly?
- Is its workflow use case described?
- Is the latest good version easy for the team to find?
